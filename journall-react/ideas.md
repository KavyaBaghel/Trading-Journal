# Journall React — Phase 0 Design Notes

## Three stylistic approaches

### Theme Name: Amber Terminal Ledger

**Very Brief Intro:** A restrained financial-terminal shell with a near-black field, amber status light, and precise mono details. It establishes continuity with the legacy journal without suggesting that product screens have already been migrated.

**Probability:** 0.07

### Theme Name: Smoked Glass Portfolio

**Very Brief Intro:** Layered translucent panels over a dark charcoal ground, using soft reflection and thin metallic borders. The tone is quieter and more editorial than a conventional admin dashboard.

**Probability:** 0.04

### Theme Name: Ledger Signal

**Very Brief Intro:** An asymmetrical status-board approach with compact system labels and an amber signal line. It is designed to make future performance data feel deliberate rather than decorative.

**Probability:** 0.09

## Chosen approach: Amber Terminal Ledger

**Design Movement:** Contemporary financial-terminal minimalism.

**Core Principles:** Near-black space carries the hierarchy; amber is reserved for system state and focus; glass panels are subtle, never luminous; typography pairs a geometric sans with a compact mono voice.

**Color Philosophy:** The inherited base remains `#010102`. Amber/gold, `#f5b84a`, is the only accent and indicates the active migration state. Neutral ink and hairlines preserve quiet contrast without any purple hue.

**Layout Paradigm:** A left-aligned terminal window with a single signal rail rather than a centered landing-page composition.

**Signature Elements:** An amber status filament, window-control dots, and a low-contrast grid texture.

**Interaction Philosophy:** This scaffold is intentionally static. Future interactions should be concise, terminal-like, and limited to transform/opacity feedback.

**Animation:** No animation in Phase 0. Future micro-interactions should remain under 180ms and respect reduced-motion preferences.

**Typography System:** Geist-like system sans for interface labels and a system monospace face for status metadata. Headings use tightly tracked, medium-weight sans text.

**Brand Essence:** Journall React is the focused migration surface for disciplined trading review. **Precise, restrained, dependable.**

**Brand Voice:** Direct, operational, and never promotional. Example lines: “Migration surface initialized.” and “Data layer arrives in Phase 1.”

**Wordmark & Logo:** A compact J-shaped terminal cursor mark followed by the JOURNALL wordmark, both drawn in amber and charcoal rather than a default wordmark treatment.

**Signature Brand Color:** Signal Amber `#f5b84a`.
